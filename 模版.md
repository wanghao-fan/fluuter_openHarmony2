# 功能代码实现

## 底部导航栏状态保持组件

底部导航栏是移动应用中常见的UI组件，用于在不同功能模块之间快速切换。在Flutter中实现底部导航栏并保持页面状态是一个常见的需求，本次实战我们将详细讲解如何实现这一功能。

### 核心实现原理

我们使用`Offstage`和`PageController`组合的方式来实现页面状态保持：

1. **Offstage**：控制子组件是否在视觉上可见，但不会从Widget树中移除
2. **PageController**：管理页面的状态和滚动
3. **Stack**：将多个页面叠加在一起，通过Offstage控制显示

### 具体组件实现

#### 1. 主导航组件 (`BottomNavigationBarDemo`)

这是整个底部导航栏的核心组件，负责管理三个页面的切换和状态保持。

```dart
import 'package:flutter/material.dart';

/// 底部导航栏状态保持组件
class BottomNavigationBarDemo extends StatefulWidget {
  const BottomNavigationBarDemo({super.key});

  @override
  State<BottomNavigationBarDemo> createState() => _BottomNavigationBarDemoState();
}

class _BottomNavigationBarDemoState extends State<BottomNavigationBarDemo> {
  // 当前选中的页面索引
  int _currentIndex = 0;
  
  // 页面控制器，用于管理页面状态
  final List<PageController> _pageControllers = [
    PageController(),
    PageController(),
    PageController(),
  ];

  @override
  void dispose() {
    // 清理页面控制器
    for (var controller in _pageControllers) {
      controller.dispose();
    }
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: Stack(
        children: [
          // 首页页面
          Offstage(
            offstage: _currentIndex != 0,
            child: PageView(
              controller: _pageControllers[0],
              physics: const NeverScrollableScrollPhysics(),
              children: [
                HomePage(),
              ],
            ),
          ),
          
          // 发现页面
          Offstage(
            offstage: _currentIndex != 1,
            child: PageView(
              controller: _pageControllers[1],
              physics: const NeverScrollableScrollPhysics(),
              children: [
                DiscoveryPage(),
              ],
            ),
          ),
          
          // 我的页面
          Offstage(
            offstage: _currentIndex != 2,
            child: PageView(
              controller: _pageControllers[2],
              physics: const NeverScrollableScrollPhysics(),
              children: [
                ProfilePage(),
              ],
            ),
          ),
        ],
      ),
      bottomNavigationBar: BottomNavigationBar(
        currentIndex: _currentIndex,
        onTap: (index) {
          setState(() {
            _currentIndex = index;
          });
        },
        type: BottomNavigationBarType.fixed,
        selectedItemColor: Colors.deepPurple,
        unselectedItemColor: Colors.grey,
        selectedFontSize: 12,
        unselectedFontSize: 12,
        items: const [
          BottomNavigationBarItem(
            icon: Icon(Icons.home),
            label: '首页',
          ),
          BottomNavigationBarItem(
            icon: Icon(Icons.explore),
            label: '发现',
          ),
          BottomNavigationBarItem(
            icon: Icon(Icons.person),
            label: '我的',
          ),
        ],
      ),
    );
  }
}
```

**实现要点**：
- 使用`Stack`组件叠加三个页面
- 每个页面使用`Offstage`包裹，通过`offstage`属性控制是否显示
- 每个页面使用`PageView`和`PageController`组合，实现状态保持
- 设置`physics: const NeverScrollableScrollPhysics()`禁止页面左右滑动
- 在`dispose`方法中清理所有`PageController`，避免内存泄漏

#### 3. 发现页面 (`DiscoveryPage`)

发现页面包含一个可添加项目的列表，用于演示列表状态的保持。

```dart
class DiscoveryPage extends StatefulWidget {

              fontSize: 24,
              fontWeight: FontWeight.bold,
            ),

              shape: RoundedRectangleBorder(
                borderRadius: BorderRadius.circular(8),
              ),
            ),
            child: const Text(
              '添加发现项',
              style: TextStyle(fontSize: 16),
            ),
          ),
          const SizedBox(height: 40),
          const Text(
            '发现列表:',
            style: TextStyle(fontSize: 16),
          ),
          const SizedBox(height: 20),
          Expanded(
            child: ListView.builder(
              itemCount: _discoveredItems.length,
              itemBuilder: (context, index) {
                return Card(
                  margin: const EdgeInsets.symmetric(vertical: 8),
                  child: Padding(
                    padding: const EdgeInsets.all(16),
                    child: Text(
                      _discoveredItems[index],
                      style: const TextStyle(fontSize: 16),

                  ),
                );
              },
            ),
          ),
          const SizedBox(height: 20),
          const Text(
            '切换到其他页面后再返回，发现列表会保持不变',

              fontSize: 14,
              color: Colors.grey,

          ),
        ],
      ),
    );
  }
}
```

**实现要点**：
- 使用`List<String>`存储发现项数据
- `_addDiscoveredItem`方法用于添加新的发现项
- 使用`ListView.builder`构建动态列表，提高性能
- 列表项使用`Card`组件包裹，增强视觉效果
- 使用`Expanded`组件使列表占满剩余空间

## 开发中需要注意的点

1. **内存管理**：使用`PageController`时，一定要在`dispose`方法中清理，避免内存泄漏

2. **性能优化**：对于复杂页面，建议使用`ListView.builder`等懒加载组件，提高列表性能

3. **布局适配**：使用`Container`的`padding`属性和`SizedBox`组件控制间距，确保在不同屏幕尺寸下的显示效果

4. **视觉一致性**：统一使用主题色（如本例中的紫色），保持应用的视觉一致性

5. **状态管理**：对于简单的页面状态，使用`StatefulWidget`即可；对于复杂的应用状态，建议使用Provider、Bloc等状态管理方案

# 本次开发中容易遇到的问题

1. **Card组件padding参数错误**

   **问题描述**：在使用`Card`组件时，错误地直接使用了`padding`参数，导致编译错误。

   **错误代码**：
   ```dart
   Card(
     margin: const EdgeInsets.symmetric(vertical: 8),
     padding: const EdgeInsets.all(16), // 错误：Card组件没有padding参数
     child: Text(
       _discoveredItems[index],
       style: const TextStyle(fontSize: 16),
     ),
   );
   ```

   **解决方案**：在`Card`的`child`中使用`Padding`组件
   ```dart
   Card(
     margin: const EdgeInsets.symmetric(vertical: 8),
     child: Padding(
       padding: const EdgeInsets.all(16),
       child: Text(
         _discoveredItems[index],
         style: const TextStyle(fontSize: 16),
       ),
     ),
   );
   ```

2. **页面状态丢失**

   **问题描述**：使用默认的`BottomNavigationBar`实现时，切换页面后再返回，页面状态会丢失。

   **原因**：默认情况下，`BottomNavigationBar`切换页面时会重建页面组件，导致状态丢失。

   **解决方案**：使用`Offstage`和`PageController`组合的方式，保持页面状态

3. **内存泄漏**

   **问题描述**：使用`PageController`后，没有在`dispose`方法中清理，导致内存泄漏。

   **解决方案**：在`dispose`方法中调用所有`PageController`的`dispose`方法
   ```dart
   @override
   void dispose() {
     // 清理页面控制器
     for (var controller in _pageControllers) {
       controller.dispose();
     }
     super.dispose();
   }
   ```

4. **页面滑动冲突**

   **问题描述**：使用`PageView`时，页面会默认支持左右滑动，与底部导航栏的切换逻辑冲突。

   **解决方案**：设置`physics: const NeverScrollableScrollPhysics()`禁止页面滑动

5. **布局溢出**

   **问题描述**：在小屏幕设备上，内容可能会超出屏幕范围。

   **解决方案**：使用`Expanded`组件配合`ListView`，确保内容可以滚动

# 总结本次开发中用到的技术点

1. **底部导航栏实现**
   - 使用`BottomNavigationBar`组件实现底部导航栏
   - 通过`currentIndex`和`onTap`属性管理选中状态
   - 设置`type: BottomNavigationBarType.fixed`确保在三个及以上项目时显示正常

2. **页面状态保持**
   - 使用`Offstage`组件控制页面显示/隐藏
   - 使用`PageController`和`PageView`组合实现页面状态保持
   - 通过`Stack`组件叠加多个页面

3. **布局技术**
   - 使用`Column`、`Row`等基础布局组件
   - 使用`SizedBox`控制间距
   - 使用`Expanded`实现弹性布局
   - 使用`Container`的`padding`属性控制内边距

4. **状态管理**
   - 使用`StatefulWidget`管理组件状态
   - 使用`setState`更新UI
   - 正确实现`dispose`方法清理资源

5. **UI组件**
   - 使用`Card`组件实现卡片式布局
   - 使用`ElevatedButton`实现按钮
   - 使用`Switch`组件实现开关
   - 使用`ListView.builder`实现动态列表

6. **主题配置**
   - 使用`ThemeData`配置应用主题
   - 使用`ColorScheme.fromSeed`生成配色方案
   - 设置`useMaterial3: true`使用Material 3设计规范
