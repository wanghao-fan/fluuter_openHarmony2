# 前言：跨生态开发的新机遇

在移动应用开发中，消息通知是提升用户体验的重要组成部分。当我们的Flutter应用需要适配OpenHarmony平台时，如何实现统一的消息通知功能成为了一个关键挑战。

Flutter的优势在于其跨平台能力，而another_flushbar作为一个功能强大的消息通知库，为我们提供了丰富的自定义选项。将其适配到OpenHarmony平台，不仅可以保持代码的一致性，还能确保在不同平台上获得相似的用户体验。

本文将详细介绍如何在OpenHarmony平台上集成和使用another_flushbar库，包括项目结构、代码实现、常见问题及解决方案，为开发者提供一份完整的实战指南。

# 引入第三方库 another_flushbar

在 `pubspec.yaml` 文件中添加 another_flushbar 依赖：

```yaml
dependencies:
  flutter:
    sdk: flutter
  cupertino_icons: ^1.0.8
  another_flushbar: ^1.12.30
```

然后运行 `flutter pub get` 命令安装依赖：

```bash
flutter pub get
```

# 功能代码实现

## 1. 消息通知组件设计

创建 `lib/components/flushbar_notification.dart` 文件，实现消息通知功能：

```dart
import 'package:flutter/material.dart';
import 'package:another_flushbar/flushbar.dart';

class FlushbarNotification {
  // 显示成功消息
  static void showSuccess(BuildContext context, String message) {
    Flushbar(
      title: '成功',
      message: message,
      duration: const Duration(seconds: 3),
      backgroundColor: Colors.green,
      icon: const Icon(Icons.check_circle, color: Colors.white),
      margin: const EdgeInsets.all(16),
      borderRadius: BorderRadius.circular(8),
      onTap: (flushbar) {
        flushbar.dismiss(true);
      },
    ).show(context);
  }

  // 显示错误消息
  static void showError(BuildContext context, String message) {
    Flushbar(
      title: '错误',
      message: message,
      duration: const Duration(seconds: 3),
      backgroundColor: Colors.red,
      icon: const Icon(Icons.error, color: Colors.white),
      margin: const EdgeInsets.all(16),
      borderRadius: BorderRadius.circular(8),
      onTap: (flushbar) {
        flushbar.dismiss(true);
      },
    ).show(context);
  }

  // 显示信息消息
  static void showInfo(BuildContext context, String message) {
    Flushbar(
      title: '信息',
      message: message,
      duration: const Duration(seconds: 3),
      backgroundColor: Colors.blue,
      icon: const Icon(Icons.info, color: Colors.white),
      margin: const EdgeInsets.all(16),
      borderRadius: BorderRadius.circular(8),
      onTap: (flushbar) {
        flushbar.dismiss(true);
      },
    ).show(context);
  }

  // 显示警告消息
  static void showWarning(BuildContext context, String message) {
    Flushbar(
      title: '警告',
      message: message,
      duration: const Duration(seconds: 3),
      backgroundColor: Colors.orange,
      icon: const Icon(Icons.warning, color: Colors.white),
      margin: const EdgeInsets.all(16),
      borderRadius: BorderRadius.circular(8),
      onTap: (flushbar) {
        flushbar.dismiss(true);
      },
    ).show(context);
  }

  // 显示自定义消息
  static void showCustom(
    BuildContext context,
    String title,
    String message,
    Color backgroundColor,
    IconData icon,
  ) {
    Flushbar(
      title: title,
      message: message,
      duration: const Duration(seconds: 3),
      backgroundColor: backgroundColor,
      icon: Icon(icon, color: Colors.white),
      margin: const EdgeInsets.all(16),
      borderRadius: BorderRadius.circular(8),
      onTap: (flushbar) {
        flushbar.dismiss(true);
      },
    ).show(context);
  }
}
```

# 本次开发中容易遇到的问题

## 1. 常量表达式错误

**问题**：使用 `Colors.grey.shade600` 等颜色时出现常量表达式错误

**原因**：`Colors.grey.shade600` 不是常量表达式，不能用于 `const` 构造函数中

**解决方案**：移除 `const` 关键字，使用普通构造函数

```dart
// 错误写法
const Text(
  '文本',
  style: TextStyle(
    color: Colors.grey.shade600, // 这里会报错
  ),
);

// 正确写法
Text(
  '文本',
  style: TextStyle(
    color: Colors.grey.shade600, // 正常使用
  ),
);
```

## 2. 依赖安装失败

**问题**：运行 `flutter pub get` 时出现依赖安装失败

**原因**：网络问题或版本兼容性问题

**解决方案**：
- 检查网络连接
- 尝试使用不同版本的 another_flushbar
- 运行 `flutter clean` 后重新安装

## 3. 通知不显示

**问题**：调用通知方法后，通知没有显示

**原因**：
- 上下文传递错误
- 通知被其他UI元素遮挡
- 应用处于后台状态

**解决方案**：
- 确保传递正确的 BuildContext
- 检查通知的 z-index 设置
- 在应用前台状态下测试

## 4. 平台适配问题

**问题**：在 OpenHarmony 平台上通知显示异常

**原因**：平台特性差异或权限问题

**解决方案**：
- 确保应用具有通知权限
- 测试不同 OpenHarmony 版本
- 针对平台特性进行适配
