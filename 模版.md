# 功能代码实现

## 进度弹窗组件设计

进度弹窗是移动应用中常见的交互组件，用于在执行耗时操作时向用户提供视觉反馈。本次开发中，我们设计了一个功能完善的自定义进度弹窗组件 `CustomProgressDialog`，支持三种类型的弹窗：

1. **加载中弹窗**：显示加载动画和提示信息，用于执行耗时操作时
2. **成功弹窗**：显示成功图标和提示信息，用于操作成功后
3. **错误弹窗**：显示错误图标和提示信息，用于操作失败后

### 加载中弹窗实现

加载中弹窗是最基础的类型，用于显示正在执行的操作：

```dart
static void show(
  BuildContext context,
  {
  String title = '加载中',
  String message = '请稍候...',
  bool isDismissible = false,
}) {
  // 先关闭可能存在的弹窗
  hide();

  _dialogContext = context;

  showDialog(
    context: context,
    barrierDismissible: isDismissible,
    builder: (BuildContext context) {
      return Dialog(
        backgroundColor: Colors.white,
        shape: RoundedRectangleBorder(
          borderRadius: BorderRadius.circular(12.0),
        ),
        child: Container(
          padding: const EdgeInsets.all(20.0),
          constraints: const BoxConstraints(
            minWidth: 280,
            maxWidth: 320,
          ),
          child: Column(
            mainAxisSize: MainAxisSize.min,
            children: [
              // 标题
              Text(
                title,
                style: const TextStyle(
                  fontSize: 18.0,
                  fontWeight: FontWeight.bold,
                  color: Colors.black87,
                ),
              ),
              const SizedBox(height: 16.0),
              
              // 加载动画
              const CircularProgressIndicator(
                valueColor: AlwaysStoppedAnimation<Color>(Colors.blue),
                strokeWidth: 3.0,
              ),
              const SizedBox(height: 16.0),
              
              // 消息
              Text(
                message,
                style: const TextStyle(
                  fontSize: 14.0,
                  color: Colors.black54,
                ),
                textAlign: TextAlign.center,
              ),
            ],
          ),
        ),
      );
    },
  );
}
```

### 隐藏弹窗实现

```dart
static void hide() {
  if (_dialogContext != null) {
    Navigator.of(_dialogContext!, rootNavigator: true).pop();
    _dialogContext = null;
  }
}
```

## 进度弹窗组件使用方法

在 `main.dart` 文件中，我们展示了如何使用 `CustomProgressDialog` 组件：

### 导入组件

```dart
import 'components/progress_dialog.dart';
```

### 在页面加载时使用

```dart
@override
void initState() {
  super.initState();
  
  // 页面加载时自动显示进度弹窗
  Future.delayed(const Duration(milliseconds: 500), () {
    // 显示加载中的进度弹窗
    CustomProgressDialog.show(
      context,
      title: '初始化中',
      message: '正在加载应用数据...',
    );
    
    // 3秒后隐藏加载弹窗，显示成功弹窗
    Future.delayed(const Duration(seconds: 3), () {
      CustomProgressDialog.hide();
      
      // 显示成功弹窗
      CustomProgressDialog.showSuccess(
        context,
        title: '初始化完成',
        message: '应用数据加载成功',
      );
    });
  });
}
```

## 开发注意事项

1. **上下文传递**：`CustomProgressDialog` 需要接收 `BuildContext` 参数，确保在调用时传递正确的上下文。

2. **弹窗管理**：在显示新弹窗前，应先调用 `hide()` 方法关闭可能存在的旧弹窗，避免多个弹窗叠加。

3. **异步操作**：在执行异步操作时，应使用 `Future.delayed` 或其他异步方法来控制弹窗的显示和隐藏时机。

4. **用户体验**：
   - 加载中弹窗应设置 `isDismissible = false`，防止用户误操作关闭弹窗
   - 成功和错误弹窗应设置 `isDismissible = true`，允许用户点击外部关闭弹窗

5. **样式统一**：保持弹窗的样式与应用整体风格一致，包括颜色、字体大小和圆角等。

# 本次开发中容易遇到的问题

1. **上下文获取问题**：在某些情况下，可能会遇到无法获取正确 `BuildContext` 的问题。解决方案是确保在有上下文的地方调用弹窗方法，或者使用 `GlobalKey` 来获取应用的根上下文。

2. **弹窗不显示问题**：如果弹窗不显示，可能是因为：
   - 上下文不正确
   - 代码执行顺序问题
   - 弹窗被其他组件遮挡

3. **弹窗无法关闭问题**：如果弹窗无法关闭，可能是因为：
   - `_dialogContext` 为 null
   - 调用 `hide()` 方法时的上下文与显示弹窗时的上下文不一致

4. **样式调整问题**：在不同设备和屏幕尺寸上，弹窗的样式可能需要调整。建议使用 `MediaQuery` 来获取屏幕尺寸，动态调整弹窗大小。

5. **性能问题**：如果频繁显示和隐藏弹窗，可能会影响应用性能。建议合理控制弹窗的显示时机和频率。

# 总结本次开发中用到的技术点

1. **组件化开发**：将进度弹窗封装为独立的 `CustomProgressDialog` 组件，提高了代码的复用性和可维护性。

2. **静态方法设计**：使用静态方法来实现弹窗的显示和隐藏，简化了调用方式，无需创建组件实例。

3. **Flutter 布局系统**：使用 `Column`、`Container`、`Text` 等 Flutter 内置组件构建弹窗布局，实现了美观的视觉效果。

4. **Material Design 组件**：使用 `Dialog`、`CircularProgressIndicator`、`ElevatedButton` 等 Material Design 组件，确保了弹窗的视觉一致性。

5. **异步编程**：使用 `Future.delayed` 来控制弹窗的显示和隐藏时机，实现了流畅的用户体验。

6. **可选参数**：使用 Dart 的可选命名参数，为弹窗方法提供了灵活的配置选项。

7. **状态管理**：使用静态变量 `_dialogContext` 来管理弹窗的上下文，确保能够正确关闭弹窗。

通过本次开发，我们实现了一个功能完善、样式美观的进度弹窗组件，为应用提供了良好的用户反馈机制。该组件不仅适用于 Flutter 应用，也可以在 Flutter for OpenHarmony 项目中正常使用，为跨平台开发提供了便利。
