# 功能代码实现

## 1. 关系图数据模型设计

### 1.1 核心数据类

关系图的实现首先需要设计合理的数据模型，我们创建了以下核心数据类：

```dart
/// 关系图节点数据模型
class RelationshipNode {
  final String id;         // 节点ID
  final String name;       // 节点名称
  final int symbolSize;    // 节点大小
  final String category;   // 节点分类
  final Color color;       // 节点颜色

  RelationshipNode({
    required this.id,
    required this.name,
    required this.symbolSize,
    required this.category,
    required this.color,
  });

  Map<String, dynamic> toJson() {
    final alpha = (color.a * 255).round();
    final red = (color.r * 255).round();
    final green = (color.g * 255).round();
    final blue = (color.b * 255).round();
    final hexColor = '#${(alpha << 24 | red << 16 | green << 8 | blue).toRadixString(16).padLeft(8, '0')}';
    
    return {
      'id': id,
      'name': name,
      'symbolSize': symbolSize,
      'category': category,
      'itemStyle': {
        'color': hexColor, // 转换为十六进制颜色
      },
    };
  }
}

/// 关系图边数据模型
class RelationshipLink {
  final String source;     // 源节点ID
  final String target;     // 目标节点ID
  final int value;         // 边的权重
  final Color lineStyle;   // 边的颜色

  RelationshipLink({
    required this.source,
    required this.target,
    required this.value,
    required this.lineStyle,
  });

  Map<String, dynamic> toJson() {
    final alpha = (lineStyle.a * 255).round();
    final red = (lineStyle.r * 255).round();
    final green = (lineStyle.g * 255).round();
    final blue = (lineStyle.b * 255).round();
    final hexColor = '#${(alpha << 24 | red << 16 | green << 8 | blue).toRadixString(16).padLeft(8, '0')}';
    
    return {
      'source': source,
      'target': target,
      'value': value,
      'lineStyle': {
        'color': hexColor, // 转换为十六进制颜色
        'width': value / 10, // 根据权重设置线宽
      },
    };
  }
}

/// 关系图分类数据模型
class RelationshipCategory {
  final String name;       // 分类名称

  RelationshipCategory({
    required this.name,
  });

  Map<String, dynamic> toJson() {
    return {
      'name': name,
    };
  }
}

/// 关系图数据模型
class RelationshipChartData {
  final List<RelationshipNode> nodes;      // 节点列表
  final List<RelationshipLink> links;      // 边列表
  final List<RelationshipCategory> categories; // 分类列表

  RelationshipChartData({
    required this.nodes,
    required this.links,
    required this.categories,
  });

  Map<String, dynamic> toJson() {
    return {
      'nodes': nodes.map((node) => node.toJson()).toList(),
      'links': links.map((link) => link.toJson()).toList(),
      'categories': categories.map((category) => category.toJson()).toList(),
    };
  }
}
```

### 1.2 数据模型设计要点

- **数据结构清晰**：通过独立的类分别管理节点、边和分类数据，职责明确
- **JSON序列化支持**：每个类都实现了`toJson()`方法，方便将数据转换为ECharts所需的JSON格式
- **颜色处理**：将Flutter的`Color`对象转换为ECharts支持的十六进制颜色字符串
- **权重映射**：在边的`toJson()`方法中，根据权重值动态计算线宽

## 2. 关系图核心组件实现

### 2.1 关系图组件

```dart
/// 关系图核心组件
class RelationshipChartWidget extends StatefulWidget {
  final RelationshipChartData data;  // 关系图数据
  final Function(Map<String, dynamic>)? onNodeClick;  // 节点点击回调
  final Function(Map<String, dynamic>)? onLinkClick;  // 边点击回调

  const RelationshipChartWidget({
    super.key,
    required this.data,
    this.onNodeClick,
    this.onLinkClick,
  });

  @override
  State<RelationshipChartWidget> createState() => _RelationshipChartWidgetState();
}

class _RelationshipChartWidgetState extends State<RelationshipChartWidget> {
  late String _option;

  @override
  void initState() {
    super.initState();
    _initOption();
  }

  @override
  void didUpdateWidget(covariant RelationshipChartWidget oldWidget) {
    super.didUpdateWidget(oldWidget);
    if (oldWidget.data != widget.data) {
      _initOption();
    }
  }

  void _initOption() {
    final optionMap = {
      'title': {
        'text': '关系网络图',
        'subtext': 'Flutter for OpenHarmony',
        'top': 'top',
        'left': 'center',
      },
      'tooltip': {
        'trigger': 'item',
        'formatter': '''
          function(params) {
            if (params.dataType === 'node') {
              return params.name + '\\n' + '分类: ' + params.data.category + '\\n' + '大小: ' + params.data.symbolSize;
            } else if (params.dataType === 'edge') {
              return params.data.source + ' -> ' + params.data.target + '\\n' + '强度: ' + params.data.value;
            }
            return '';
          }
        ''',
      },
      'legend': {
        'data': widget.data.categories.map((category) => category.name).toList(),
        'orient': 'vertical',
        'left': 'left',
      },
      'series': [
        {
          'type': 'graph',
          'layout': 'force',
          'data': widget.data.nodes.map((node) => node.toJson()).toList(),
          'links': widget.data.links.map((link) => link.toJson()).toList(),
          'categories': widget.data.categories.map((category) => category.toJson()).toList(),
          'roam': true,
          'label': {
            'show': true,
            'position': 'right',
            'formatter': '{b}',
          },
          'lineStyle': {
            'color': 'source',
            'curveness': 0.3,
          },
          'emphasis': {
            'focus': 'adjacency',
            'lineStyle': {
              'width': 10,
            },
          },
          'force': {
            'repulsion': 100,
            'edgeLength': [40, 100],
          },
          'itemStyle': {
            'borderColor': '#fff',
            'borderWidth': 1,
          },
        },
      ],
    };
    _option = json.encode(optionMap);
  }

  @override
  Widget build(BuildContext context) {
    return Echarts(
      option: _option,
      extensions: [
        // 可以添加自定义扩展
      ],
      onMessage: (String message) {
        final Map<String, dynamic> data = _parseJsObject(message);
        if (data['type'] == 'click') {
          if (data['dataType'] == 'node') {
            widget.onNodeClick?.call(data['data']);
          } else if (data['dataType'] == 'edge') {
            widget.onLinkClick?.call(data['data']);
          }
        }
      },
    );
  }

  Map<String, dynamic> _parseJsObject(String message) {
    // 简单的JSON解析
    try {
      return json.decode(message);
    } catch (e) {
      return {};
    }
  }
}
```

### 2.2 组件实现要点

- **ECharts集成**：使用`flutter_echarts`库实现关系图的渲染
- **配置动态生成**：在`_initOption()`方法中根据传入的数据动态生成ECharts配置
- **交互处理**：通过`onMessage`回调处理节点和边的点击事件
- **响应式更新**：实现`didUpdateWidget`方法，当数据变化时重新生成配置
- **力导向布局**：使用ECharts的`force`布局算法，使关系图自动布局更美观

   ```yaml
   dependencies:
     flutter:
       sdk: flutter
   ```

   ```dart
   import 'package:aa/components/relationship_chart.dart';
   ```

   ```dart
   final categories = [
     RelationshipCategory(name: '人物'),

   // 创建节点和边...
   ```

   ```dart
   RelationshipChartWidget(

   ```

### 4.2 开发注意事项

1. **平台兼容性**：
   - Web平台：由于`flutter_echarts`依赖WebView，在Web平台上可能会遇到`setBackgroundColor`未实现的问题
   - 移动端：在Android和iOS平台上可以正常运行

2. **数据规模**：
   - 节点和边的数量不宜过多，否则可能会影响性能
   - 建议对大规模数据进行分页或聚类处理

3. **性能优化**：
   - 使用`const`构造器创建不变的Widget
   - 避免在`build`方法中重复计算
   - 考虑使用`AutomaticKeepAliveClientMixin`保持状态

4. **交互体验**：
   - 合理设置力导向布局参数，使关系图布局更美观
   - 添加适当的动画效果，提升用户体验
   - 实现清晰的点击反馈机制

# 本次开发中容易遇到的问题

## 1. Web平台兼容性问题

### 问题描述
在Web平台上运行应用时，出现以下错误：
```
UnimplementedError: setBackgroundColor is not implemented on the current platform
```

### 原因分析
- `flutter_echarts`库在Web平台上使用WebView实现图表渲染
- WebView的`setBackgroundColor`方法在Web平台上未实现
- 这是一个平台特定的API限制，而非代码逻辑错误

### 解决方案
- 添加平台检测，在Web平台上显示替代内容
- 使用`kIsWeb`常量判断当前平台
- 为Web平台提供友好的提示信息

## 2. 数据转换问题

### 问题描述
- ECharts需要JSON格式的数据，而Flutter使用Dart对象
- 颜色格式不兼容，Flutter使用`Color`对象，ECharts使用十六进制颜色字符串

### 解决方案
- 为每个数据类实现`toJson()`方法
- 编写颜色转换工具，将Flutter的`Color`对象转换为十六进制颜色字符串
- 确保数据结构符合ECharts的要求

## 3. 性能优化问题

### 问题描述
- 当关系图节点和边数量较多时，渲染性能下降
- 频繁的数据更新可能导致UI卡顿

### 解决方案
- 合理设置ECharts的配置参数，如`force`布局参数
- 使用`didUpdateWidget`方法，只在数据变化时重新生成配置
- 考虑对大规模数据进行分层渲染或懒加载

## 4. 依赖版本问题

### 问题描述
- `flutter_echarts`库的不同版本可能存在API差异
- 版本不兼容可能导致编译错误或运行时异常

### 解决方案
- 在`pubspec.yaml`中明确指定依赖版本
- 定期更新依赖，修复已知问题
- 测试不同平台上的兼容性
