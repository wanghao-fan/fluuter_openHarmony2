# 前言：跨生态开发的新机遇

在移动应用开发中，处理长文本展示是一个常见的挑战。当我们的Flutter应用需要适配OpenHarmony平台时，如何实现统一的文本展开和折叠功能成为了一个重要需求。

Flutter的优势在于其跨平台能力，而readmore作为一个轻量级的文本处理库，为我们提供了简单而强大的文本展开和折叠功能。将其适配到OpenHarmony平台，不仅可以保持代码的一致性，还能确保在不同平台上获得相似的用户体验。

本文将详细介绍如何在OpenHarmony平台上集成和使用readmore库，包括项目结构、代码实现、常见问题及解决方案，为开发者提供一份完整的实战指南。

import 'package:flutter/material.dart';
import 'package:readmore/readmore.dart';

class ExpandableText extends StatelessWidget {
  final String text;
  final int trimLines;
  final TextStyle? style;
  final String readMoreText;
  final String readLessText;
  final TextStyle? expandIconStyle;
  final Color? expandIconColor;

  const ExpandableText({
    Key? key,
    required this.text,
    this.trimLines = 2,
    this.style,
    this.readMoreText = '展开',
    this.readLessText = '收起',
    this.expandIconStyle,
    this.expandIconColor,
  }) : super(key: key);

  @override
  Widget build(BuildContext context) {
    return ReadMoreText(
      text,
      trimLines: trimLines,
      trimMode: TrimMode.Line,
      style: style ?? const TextStyle(color: Colors.black),
      colorClickableText: Colors.blue,
      trimCollapsedText: readMoreText,
      trimExpandedText: readLessText,
      moreStyle: expandIconStyle ?? TextStyle(color: expandIconColor ?? Colors.blue),
      lessStyle: expandIconStyle ?? TextStyle(color: expandIconColor ?? Colors.blue),
    );
  }
}

## 4. 开发注意事项

1. **依赖版本**：确保使用兼容的 readmore 版本，本文使用的是 ^3.0.0
2. **文本长度**：确保文本长度足够长，至少超过 trimLines 指定的行数，才能触发展开/折叠功能
3. **样式统一**：保持文本样式与应用整体风格一致
4. **用户体验**：合理设置 trimLines 值，默认值为 2 行
5. **性能优化**：避免在列表中使用过多的展开/折叠文本，可能影响滚动性能

# 本次开发中容易遇到的问题

## 1. 命名冲突问题

**问题**：自定义组件与导入的库组件名称冲突

**原因**：创建了与 readmore 库中相同名称的组件 `ReadmoreText`

**解决方案**：重命名自定义组件为 `ExpandableText`，避免命名冲突

```dart
// 错误写法
class ReadmoreText extends StatelessWidget { ... }

// 正确写法
class ExpandableText extends StatelessWidget { ... }
```

## 2. 参数名称错误

**问题**：使用了不存在的参数名称

**原因**：不同版本的 readmore 库参数名称可能不同

**解决方案**：参考最新版本的文档，使用正确的参数名称

```dart
// 正确的参数
ReadMoreText(
  text,
  trimLines: trimLines,
  trimMode: TrimMode.Line,
  style: style,
  colorClickableText: Colors.blue,
  trimCollapsedText: readMoreText,
  trimExpandedText: readLessText,
  moreStyle: moreStyle,
  lessStyle: lessStyle,
);
```

## 3. 展开/折叠按钮不显示

**问题**：文本超出指定行数但没有显示展开按钮

**原因**：
- 文本长度不够，没有超过 trimLines 指定的行数
- 参数配置错误

**解决方案**：
- 确保文本长度足够长
- 正确配置 trimLines 和 trimMode 参数
- 检查文本样式是否影响了显示

## 4. 常量表达式错误

**问题**：使用 `Colors.grey.shade600` 等颜色时出现常量表达式错误

**原因**：`Colors.grey.shade600` 不是常量表达式，不能用于 `const` 构造函数中

**解决方案**：移除 `const` 关键字，使用普通构造函数

```dart
// 错误写法
const TextStyle(
  color: Colors.grey.shade600, // 这里会报错
);

// 正确写法
TextStyle(
  color: Colors.grey.shade600, // 正常使用
);
```
