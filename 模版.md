# 功能代码实现

## Toast 提示组件实现

### 组件设计思路

Toast 组件是一种轻量级的提示机制，用于向用户展示短暂的信息反馈。本次实现参考了 shadcn_ui 的设计风格，具有以下特点：

- 支持多种提示类型：成功、错误、警告、信息
- 每种类型有对应的颜色和图标
- 自动消失，无需用户交互
- 居中显示，不遮挡主要内容

### 核心代码实现

#### 1. Toast 组件定义

```dart
import 'package:flutter/material.dart';

class ShadcnToast extends StatelessWidget {
  final String message;
  final ToastType type;
  final Duration duration;

  const ShadcnToast({
    super.key,
    required this.message,
    this.type = ToastType.info,
    this.duration = const Duration(seconds: 3),
  });

  @override
  Widget build(BuildContext context) {
    return Container(
      padding: const EdgeInsets.symmetric(horizontal: 16, vertical: 10),
      decoration: BoxDecoration(
        color: _getBackgroundColor(),
        borderRadius: BorderRadius.circular(8),
        boxShadow: [
          BoxShadow(
            color: Colors.black.withOpacity(0.1),
            spreadRadius: 0,
            blurRadius: 8,
            offset: const Offset(0, 4),
          ),
        ],
      ),
      child: Row(
        mainAxisSize: MainAxisSize.min,
        children: [
          Icon(
            _getIcon(),
            size: 16,
            color: _getTextColor(),
          ),
          const SizedBox(width: 8),
          Text(
            message,
            style: TextStyle(
              color: _getTextColor(),
              fontSize: 14,
              fontWeight: FontWeight.w500,
            ),
          ),
        ],
      ),
    );
  }

  Color _getBackgroundColor() {
    switch (type) {
      case ToastType.success:
        return const Color(0xFFECFDF5);
      case ToastType.error:
        return const Color(0xFFFEF2F2);
      case ToastType.warning:
        return const Color(0xFFFFFAEB);
      case ToastType.info:
      default:
        return const Color(0xFFEFF6FF);
    }
  }

  Color _getTextColor() {
    switch (type) {
      case ToastType.success:
        return const Color(0xFF10B981);
      case ToastType.error:
        return const Color(0xFFEF4444);
      case ToastType.warning:
        return const Color(0xFFF59E0B);
      case ToastType.info:
      default:
        return const Color(0xFF3B82F6);
    }
  }

  IconData _getIcon() {
    switch (type) {
      case ToastType.success:
        return Icons.check_circle;
      case ToastType.error:
        return Icons.error;
      case ToastType.warning:
        return Icons.warning;
      case ToastType.info:
      default:
        return Icons.info;
    }
  }
}

enum ToastType {
  success,
  error,
  warning,
  info,
}
```

#### 2. Toast 服务实现

为了方便使用，我们创建了一个 ToastService 类来管理 Toast 的显示和隐藏：

```dart
class ToastService {
  static void show(BuildContext context, String message, {
    ToastType type = ToastType.info,
    Duration duration = const Duration(seconds: 3),
  }) {
    final overlayState = Overlay.of(context);
    final overlayEntry = OverlayEntry(
      builder: (context) => Positioned(
        top: 50,
        left: 0,
        right: 0,
        child: Center(
          child: ShadcnToast(
            message: message,
            type: type,
            duration: duration,
          ),
        ),
      ),
    );

    overlayState.insert(overlayEntry);

    Future.delayed(duration, () {
      overlayEntry.remove();
    });
  }
}
```

### 组件使用方法

在首页中，我们创建了四个按钮，分别用于触发不同类型的提示：

```dart
import 'package:flutter/material.dart';
import 'package:aa/components/toast.dart';

class _MyHomePageState extends State<MyHomePage> {
  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('Shadcn UI Toast Demo'),
        backgroundColor: const Color(0xFF1E293B),
        foregroundColor: Colors.white,
      ),
      body: Center(
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: <Widget>[
            const Text(
              'Click buttons to show different toasts',
              style: TextStyle(
                fontSize: 18,
                fontWeight: FontWeight.w500,
              ),
            ),
            const SizedBox(height: 32),
            Row(
              mainAxisAlignment: MainAxisAlignment.center,
              children: [
                _buildToastButton(
                  context,
                  'Success',
                  ToastType.success,
                  const Color(0xFF10B981),
                ),
                const SizedBox(width: 16),
                _buildToastButton(
                  context,
                  'Error',
                  ToastType.error,
                  const Color(0xFFEF4444),
                ),
              ],
            ),
            const SizedBox(height: 16),
            Row(
              mainAxisAlignment: MainAxisAlignment.center,
              children: [
                _buildToastButton(
                  context,
                  'Warning',
                  ToastType.warning,
                  const Color(0xFFF59E0B),
                ),
                const SizedBox(width: 16),
                _buildToastButton(
                  context,
                  'Info',
                  ToastType.info,
                  const Color(0xFF3B82F6),
                ),
              ],
            ),
          ],
        ),
      ),
    );
  }

  Widget _buildToastButton(BuildContext context, String label, ToastType type, Color color) {
    return ElevatedButton(
      onPressed: () {
        ToastService.show(
          context,
          'This is a $label toast message',
          type: type,
        );
      },
      style: ElevatedButton.styleFrom(
        backgroundColor: color,
        foregroundColor: Colors.white,
        padding: const EdgeInsets.symmetric(horizontal: 20, vertical: 12),
        shape: RoundedRectangleBorder(
          borderRadius: BorderRadius.circular(8),
        ),
      ),
      child: Text(label),
    );
  }
}
```

### 开发中需要注意的点

1. **Overlay 权限**：Toast 组件使用了 Flutter 的 Overlay 机制来显示，需要确保在有 Overlay 的上下文中调用 `ToastService.show()` 方法。

2. **上下文传递**：确保传递的 BuildContext 是有效的，否则可能会导致 Overlay.of(context) 返回 null。

3. **样式一致性**：为了保持 shadcn_ui 的设计风格，需要注意颜色、字体、阴影等样式的一致性。

4. **性能考虑**：虽然 Toast 组件是轻量级的，但在频繁调用时仍需注意性能影响，建议合理控制显示频率。

5. **平台适配**：在 OpenHarmony 平台上，需要确保组件的显示效果与 Android 和 iOS 平台一致。

# 本次开发中容易遇到的问题

1. **依赖版本问题**：在添加 `tailwind_colors` 依赖时，最初指定的版本 ^2.0.0 不存在，导致依赖解析失败。解决方案是使用存在的版本 ^0.3.1。

2. **Web 平台构建错误**：在构建过程中遇到了与 `url_launcher_web` 和 `flutter_web_plugins` 相关的错误。解决方案是执行 `flutter clean` 清理项目，然后重新获取依赖。

3. **Overlay 上下文问题**：在某些情况下，传递给 `ToastService.show()` 的 BuildContext 可能没有关联的 Overlay，导致无法显示 Toast。解决方案是确保在有 Overlay 的上下文中调用该方法，例如在 Scaffold 内部。

4. **样式适配问题**：在不同平台上，Toast 组件的显示效果可能会有细微差异。解决方案是使用平台无关的样式定义，确保在所有平台上都能保持一致的视觉效果。

# 总结本次开发中用到的技术点

1. **组件化开发**：将 Toast 组件抽离为独立的模块，提高了代码的可维护性和复用性。

2. **Overlay 机制**：使用 Flutter 的 Overlay 机制来显示 Toast，实现了不影响主界面的提示效果。

3. **枚举类型**：使用枚举类型定义 Toast 的不同类型，使代码更加清晰易读。

4. **服务类设计**：创建 ToastService 类来管理 Toast 的显示和隐藏，提供了简洁的 API 接口。

5. **响应式布局**：使用 Row 和 Center 等布局组件，确保 Toast 在不同屏幕尺寸上都能正确显示。

6. **样式设计**：参考 shadcn_ui 的设计风格，实现了美观、一致的视觉效果。

7. **平台适配**：确保 Toast 组件在 OpenHarmony 平台上的显示效果与其他平台一致。

8. **依赖管理**：正确配置和管理项目依赖，确保依赖版本的兼容性。

通过本次实践，我们成功实现了 shadcn_ui 风格的提示组件在 OpenHarmony 上的适配，为跨平台开发提供了一个实用的组件示例。同时，我们也积累了一些跨平台开发的经验和解决方案，为后续的开发工作打下了基础。
